# ✊ Rock Paper Scissors – Fun Game

A fun and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.

The player competes against the computer, which randomly selects Rock, Paper, or Scissors. The game determines the winner and keeps track of the score.

## 🚀 Features

* ✊ Rock selection
* ✋ Paper selection
* ✌️ Scissors selection
* 🤖 Computer randomly chooses an option
* 🏆 Automatically determines the winner
* 📊 Score tracking
* 🔄 Play multiple rounds
* 🎨 Interactive and responsive UI
* ⚡ Instant game results

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling, layout, and animations
* **JavaScript** – Game logic and DOM manipulation

## 🎮 How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer will randomly select its choice.
3. The game compares both choices.
4. The winner is displayed on the screen.
5. The score is updated automatically.
6. Keep playing and try to beat the computer!

### Game Rules

| Player Choice | Beats       |
| ------------- | ----------- |
| ✊ Rock        | ✌️ Scissors |
| ✋ Paper       | ✊ Rock      |
| ✌️ Scissors   | ✋ Paper     |

If both players choose the same option, the round is a **Draw**.
